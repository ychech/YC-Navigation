# 后台系统

Artistic Nav 提供完整的后台管理系统。

## 登录

访问 `/admin` 进入后台登录页。

默认账号：
- 用户名: `admin`
- 密码: `admin123456`

**⚠️ 生产环境请务必修改默认密码！**

## 仪表盘

登录后显示仪表盘：

- 总链接数
- 总访问量
- 热门链接
- 访问趋势

## 功能模块

### 链接管理

- 添加/编辑/删除链接
- 批量操作
- 搜索过滤

### 分类管理

- 添加/编辑/删除分类
- 调整排序
- 设置图标

### 画廊管理

- 上传图片
- 创建相册
- 图片排序

### 系统设置

- 修改密码
- 配置站点信息
- 备份数据

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + K` | 打开搜索 |
| `Ctrl + S` | 保存 |
| `Esc` | 取消/关闭 |

## 移动端访问

后台支持移动端访问，完美适配手机和平板。
