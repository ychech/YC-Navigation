# 后台管理系统

YC-Navigation 提供完整的后台管理系统，采用黑白极简艺术风格设计。

## 登录

访问 `/admin` 进入后台登录页。

默认账号：
- 用户名: `admin`
- 密码: `admin123`

**⚠️ 首次登录后请立即修改默认密码！**

---

## 后台结构

后台采用侧边栏导航布局，分为以下几个模块：

### 内容管理

#### 链接
管理导航链接的分类和链接内容。

- **添加分类**：创建新的链接分类
- **添加链接**：在分类下添加链接
- **编辑/删除**：修改或删除现有内容
- **搜索**：快速查找链接

#### 画廊
管理画廊页面的图片展示。

- 上传图片
- 添加图片标题
- 删除图片

### 首页配置

#### 首页标题
配置首页顶部 Hero 区域显示的大标题和副标题。

| 字段 | 说明 | 示例 |
|------|------|------|
| 首页大标题 | 主标题 | 灵感与设计的边界 |
| 首页副标题 | 副标题描述 | 一个精心策划的数字档案馆... |

#### 尾部幻灯片
配置首页下方区域显示的内容，支持两种模式：

**幻灯片模式**
- 添加多个幻灯片
- 每个幻灯片包含：标题、副标题、描述、代码片段
- 前台自动轮播显示
- 可启用/禁用单个幻灯片

**关于内容模式**
- 简单的标题和描述
- 当没有幻灯片时默认显示

### 站点配置

配置全局站点信息和安全设置。

#### 站点信息
| 字段 | 说明 |
|------|------|
| 站点名称 | 显示在导航栏 |
| 站点标语 | 显示在导航栏 |
| 版权信息 | 显示在页脚 |
| 联系邮箱 | 页脚联系链接 |

#### 修改密码
修改后台登录密码。

## 前后台对应关系

| 后台管理 | 前台显示位置 |
|---------|------------|
| 链接 → 分类/链接 | 首页链接目录 |
| 画廊 | `/gallery` 页面 |
| 首页标题 | 首页顶部 Hero 区域 |
| 尾部幻灯片 | 首页下方 About 区域 |
| 站点配置 → 站点名称/标语 | 导航栏 |
| 站点配置 → 版权/邮箱 | 页脚 |

---

## 界面说明

### 侧边栏
- 可折叠展开（点击顶部箭头）
- 显示链接数、图片数统计
- 底部有主题切换和退出按钮

### 黑白艺术风格
- 纯白 / 纯黑背景
- 无渐变、无彩色装饰
- 简洁的边框和排版
- 悬停时颜色反转效果

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + K` | 打开搜索（前台） |
| `Esc` | 关闭弹窗/取消编辑 |
