# 画廊展示

画廊功能用于展示图片和创意作品。

## 启用画廊

在后台 "画廊管理" 中启用画廊功能。

## 上传图片

支持以下方式：

### 本地上传

直接拖拽或选择图片文件：
- 格式: JPG, PNG, GIF, WebP
- 大小: 单张最大 5MB

### 阿里云 OSS

配置 OSS 后，图片将上传到云端：

```env
OSS_REGION=oss-cn-hangzhou
OSS_BUCKET=your-bucket
```

## 创建相册

1. 进入 "画廊管理"
2. 点击 "新建相册"
3. 设置相册名称和封面
4. 添加图片

## 前端展示

画廊在前端以瀑布流布局展示：

- 支持懒加载
- 点击图片放大查看
- 支持键盘导航

## 图片优化

自动进行图片优化：

- 生成缩略图
- WebP 格式转换
- 懒加载

## API

获取画廊列表：

```http
GET /api/gallery
```

获取相册详情：

```http
GET /api/gallery/:id
```
