# 导航管理

Artistic Nav 提供直观的导航管理功能。

## 添加链接

1. 登录后台管理 `/admin`
2. 点击 "链接管理"
3. 点击 "添加链接"
4. 填写信息：
   - 标题
   - URL
   - 描述（可选）
   - 图标（可选）
   - 分类

## 分类管理

分类用于组织链接：

- **设计工具**: Figma, Sketch, Adobe XD
- **开发工具**: VS Code, GitHub, Stack Overflow
- **学习资源**: 教程、文档、博客

### 创建分类

1. 进入 "分类管理"
2. 点击 "添加分类"
3. 设置：
   - 分类名称
   - 图标
   - 排序权重

## 图标设置

支持以下方式添加图标：

1. **上传图片**: PNG, SVG 格式
2. **图标库**: 使用 Lucide 图标
3. **外部链接**: 输入图片 URL

## 排序与置顶

- 拖拽调整链接顺序
- 设置置顶链接显示在最前

## 导入导出

支持批量导入导出链接：

```json
[
  {
    "title": "Figma",
    "url": "https://figma.com",
    "category": "design"
  }
]
```
